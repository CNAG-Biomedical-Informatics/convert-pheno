# Citation for Convert-Pheno

:::info[Citation]
Rueda M, et al. Convert-Pheno: A software toolkit for the interconversion of standard data models for phenotypic data. J Biomed Inform. 2023 Nov 28:104558. [doi: 10.1016/j.jbi.2023.104558](https://doi.org/10.1016/j.jbi.2023.104558). PMID: 38035971.

:::

:::note[Publication scope]
The software paper describes the feature set available at publication time.
This documentation follows the current release and therefore includes later
formats, output routes, and multi-entity BFF support that are not covered in
the original article.
:::

## Publications and Related Work

- **Convert-Pheno software paper:** the main citation for the tool is the Journal of Biomedical Informatics article listed above.
- **OMOP-CDM to Beacon v2 mapping work:** Rueda M, et al. *Enhancing semantic interoperability in precision medicine: converting OMOP CDM to Beacon v2 in the Spanish IMPaCT-Data project*. BMC Medical Informatics and Decision Making. 2026. [doi: 10.1186/s12911-026-03649-0](https://doi.org/10.1186/s12911-026-03649-0). The accompanying [tutorial repository](https://github.com/CNAG-Biomedical-Informatics/omop-cdm-2-beacon-v2) documents the mapping workflow implemented in `Convert-Pheno`.
