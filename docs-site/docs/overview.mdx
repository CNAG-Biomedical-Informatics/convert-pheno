This documentation tracks `Convert-Pheno 0.35`.

Developers can integrate the same conversion engine through the
[HTTP(s) API](use-as-an-api) or [Perl/Python interfaces](use-as-a-module).
:::
## Typical conversions

Examples include:

- convert [Phenopackets](pxf) to Beacon collections, or Beacon individuals to Phenopackets
- convert [OMOP-CDM exports](omop2bff) to Beacon
- map [REDCap](redcap) or [CSV](csv) fields to Beacon or OMOP-CDM using a **mapping file**
- convert [FHIR](fhir), [CDISC Dataset-JSON](dataset-json), or [Dataset-XML](dataset-xml) to Beacon or Phenopackets
- export [Beacon individuals](bff) as OMOP-CDM tables, flattened CSV, or JSON-LD
