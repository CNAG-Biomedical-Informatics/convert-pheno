**PXF** stands for **P**henotype e**X**change **F**ormat. See the Phenopackets
v2 [documentation](https://phenopacket-schema.readthedocs.io/en/latest/basics.html).

Phenopackets organizes information through
[top-level elements](https://phenopacket-schema.readthedocs.io/en/latest/toplevel.html).
`Convert-Pheno` processes the
[Phenopacket element](https://phenopacket-schema.readthedocs.io/en/latest/phenopacket.html)
serialized as JSON or YAML.

`Convert-Pheno` supports PXF in both directions:

- As **input**, for routes including `pxf2bff`, `pxf2omop`, and
  inspection-oriented outputs.
- As **output**, from BFF, OMOP-CDM, REDCap, CSV, CDISC-ODM, and openEHR input.

## PXF As Input

Use the small input from the [5-Minute Quickstart](quickstart), or
<PxfBiosamplesExampleDownload /> to exercise biosample conversion.

A PXF file can contain one Phenopacket object or an array of Phenopackets. BFF
individuals-only output preserves that shape.

When PXF contains `biosamples`, entity-aware BFF output maps them to first-class
Beacon `biosamples`. In individuals-only mode they are retained under
`info.phenopacket.biosamples`; `interpretations` are similarly retained in
`info.phenopacket` because they are not yet a first-class CLI output entity.

`subject.vitalStatus` is preserved under `info.phenopacket.vitalStatus` for
round trips. If no preserved value exists during BFF-to-PXF conversion, the
fallback is `ALIVE` unless `--default-vital-status` specifies another
supported status.

Use [PXF input recipes](conversion-recipes#pxf-input-bff-output) for commands
covering individuals-only, multi-entity BFF, and OMOP output.

## PXF As Output

PXF can be generated from BFF, OMOP-CDM, REDCap, CSV, CDISC-ODM, and openEHR.
Routes that do not begin with BFF normalize through the internal BFF
representation before the Phenopacket is written.

Use the relevant input section in [Choose a Conversion](conversion-recipes) for
the command. Full tested inputs and reference outputs are indexed in the
[`t/` fixture guide](https://github.com/CNAG-Biomedical-Informatics/convert-pheno/tree/main/t).
