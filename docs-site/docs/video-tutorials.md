Short demonstrations of **Convert-Pheno Desktop**, using synthetic data.
The series was recorded with version 0.35.

[Watch the Desktop tutorial playlist on YouTube](https://www.youtube.com/playlist?list=PLIMAoZdq9jK0).
You can also visit the
[YouTube channel](https://www.youtube.com/channel/UC1bjHxoYV9uGJaTyd3bZnEA).

## Tutorials

| Video | What it shows |
| --- | --- |
| Overview | Purpose, interfaces and Desktop navigation: conversions, sources, runs, outputs and resources |
| Phenopackets to Beacon | Open Desktop, load an example and inspect individuals and biosamples |
| OMOP to Beacon | Select a folder of OMOP tables, inspect output and find the OHDSI resource controls |
| CSV to OMOP | Load a mapping, review terminology, correct an alias and check the generated tables |

For installation and written instructions, see the
[Desktop guide](graphical-interface). The [mapping guide](mapping-files) and
[terminology search guide](terminology-search) explain the settings used in the
CSV tutorial.
