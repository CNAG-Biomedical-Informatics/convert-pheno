This page is a quick map of the formats that `Convert-Pheno` can read and write. For file requirements and format-specific options, use the **Format Guides** in the sidebar.

- **Inputs:** [BFF](bff), [Phenopackets v2](pxf), [OMOP-CDM](omop-cdm), [REDCap](redcap), [CDISC-ODM](cdisc-odm), [CDISC Dataset-JSON](dataset-json), [FHIR R4 Bundles](fhir), [CSV](csv), and [openEHR canonical compositions](openehr)
- **Main outputs:** BFF, Phenopackets v2, and OMOP-CDM CSV tables
- **[Inspection outputs](conversion-recipes#inspection-outputs):** flattened JSON or YAML, CSV, and JSON-LD or YAML-LD from BFF or PXF input

Most routes use BFF as the internal target model. The CLI handles any intermediate BFF conversion automatically.

## Conversion map

```mermaid

  subgraph "Target model"
    A["BFF<br/>Beacon v2 Models"]
  end

  C -->|redcap2bff| A
  E -->|cdiscodm2bff| A
  H -->|datasetjson2bff| A
  F -->|csv2bff| A
  G -->|openehr2bff| A
  J -->|fhir2bff| A
  B[Phenopackets v2] -->|pxf2bff| A
  A -->|bff2pxf| B
  D[OMOP-CDM] -->|omop2bff| A
  A -->|bff2omop| D
```
