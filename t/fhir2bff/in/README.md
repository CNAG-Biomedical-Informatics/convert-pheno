# FHIR R4 fixture provenance

`patient-bundle.json` is a reduced and curated derivative of a synthetic FHIR
R4 patient Bundle generated by [Synthea](https://github.com/synthetichealth/synthea).
The source Bundle was obtained from the official
[Synthea sample data downloads](https://synthetichealth.github.io/synthea-sample-data/downloads/latest/).

The Patient, Condition, laboratory Observation, Procedure, and
MedicationRequest examples retain the structure and synthetic terminology used
by Synthea. Convert-Pheno contributors reduced those resources and added a
Specimen, a specimen-linked Observation, an HPO-coded Observation, a
ResearchStudy, a ResearchSubject, and a Group to exercise the supported mapping
boundaries. These additions are project-authored synthetic test data and do not
represent a real person or study.
